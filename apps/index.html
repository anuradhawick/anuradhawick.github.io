Metagenomics & Plasmid Recovery

Algorithms and models developed during PhD research at the Australian National University

MetaBCC-LR

PhDt-SNEDBSCANPython

First long-read metagenomics binning tool introducing the k-mer coverage histogram concept. Uses t-SNE for dimension reduction and DBSCAN for clustering.

GitHub

LRBinner

Auto-encodersDeep LearningBinning

Unified composition and coverage binning using deep auto-encoders combined with an innovative clustering algorithm for long reads. Published in WABI 2021 and AMB.

GitHub

OBLR

Graph Neural NetworksCUDARAPIDS

Read-overlap graph binning for long reads using UMAP cluster detection and GraphSAGE representation learning, accelerated with CUDA RAPIDS.
