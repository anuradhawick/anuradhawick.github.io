Rust · AWS Lambda · Terraform · cargo-lambda

Rust AWS Lambda Template

A high-performance Rust-based AWS Lambda starter, managed using cargo-lambda and deployed via Terraform. Incorporates the lambdamux routing crate for express-style declarative route declarations with zero runtime overhead and minimal cold starts.

  • Sub-millisecond Rust execution runtime with zero cold starts
  • Declarative HTTP routing powered by the lambdamux macro crate
  • Automated local building with cargo-lambda
  • Modular Terraform modules for Lambda, IAM, and API Gateway

Database Engines & Low-Level Toolkits

Data structures, storage engine components, and custom database extension templates.

Rust · Data Structures · Storage Engines · PyPI

rs-avl — Database Development Starter

A generic, high-performance AVL tree implementation in Rust designed specifically for database storage engine development, secondary indexing, and ordered key-value lookup. Serves as the foundational indexing layer behind the avldb document database.

  • Self-balancing AVL tree with logarithmic search, insert, and delete
  • Range query iterators for indexed range scanning
  • Ceiling, floor, and nearest-neighbor key lookup methods
  • Exposed with zero-copy Python bindings on PyPI
GitHubcrates.ioPyPI
Rust · SQLite · UDFs · CLI

sqlite-functions — SQLite Extension Starter

A clean toolkit and starter template for authoring custom Rust user-defined functions (UDFs) and extensions for SQLite. Simplifies building high-performance numerical, analytical, and cryptographic functions callable directly inside SQL queries and CLI tools.

  • Ergonomic macros for registering custom scalar and aggregate functions
  • Safe memory boundary abstractions across SQLite C APIs and Rust
  • Supports standalone CLI tools with bundled SQLite functions
  • Published to crates.io for instant inclusion in Rust projects
GitHubcrates.io
